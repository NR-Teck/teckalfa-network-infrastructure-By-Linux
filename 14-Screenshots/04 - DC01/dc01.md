# 04 — DC01

## 4.1 Objetivo

O DC01 é o servidor principal da infraestrutura da TeckAlfa e desempenha as funções de controlador de domínio Active Directory através do Samba.

Este servidor disponibiliza serviços fundamentais para o funcionamento da infraestrutura, nomeadamente:

* Controlador de domínio Active Directory;
* Serviço DNS;
* Serviço Kerberos;
* Serviço LDAP;
* Serviço SMB;
* Serviços RPC;
* Global Catalog;
* Gestão de utilizadores e grupos;
* Autenticação dos equipamentos integrados no domínio.

O domínio utilizado na infraestrutura é:

`ad.teckalfa.pt`

O servidor DC01 utiliza o endereço IPv4:

`192.168.10.10`

---

## 4.2 Identificação do servidor

A identificação do servidor foi verificada através dos comandos:

```bash
hostname
hostname -f
```

Resultados obtidos:

```text
dc01.ad.teckalfa.pt
dc01.ad.teckalfa.pt
```

O resultado confirma que o servidor está identificado pelo FQDN:

`dc01.ad.teckalfa.pt`



---

## 4.3 Configuração de rede

A configuração da interface de rede do DC01 foi verificada através do comando:

```bash
ip addr
```

A interface utilizada pelo servidor é a `ens33`.

O endereço IPv4 configurado é:

`192.168.10.10/24`

A rede interna utilizada é:

`192.168.10.0/24`

O resultado obtido confirmou que a interface `ens33` se encontra activa e possui o endereço IPv4 esperado.

### Configuração de rede

| Parâmetro           | Valor                 |
| ------------------- | --------------------- |
| Servidor            | DC01                  |
| FQDN                | `dc01.ad.teckalfa.pt` |
| Interface           | `ens33`               |
| Endereço IPv4       | `192.168.10.10/24`    |
| Broadcast           | `192.168.10.255`      |
| Rede                | `192.168.10.0/24`     |
| Estado da interface | `UP`                  |

### Comando utilizado

```bash
ip addr
```



---

## 4.4 Tabela de encaminhamento

A tabela de encaminhamento do DC01 foi verificada através do comando:

```bash
ip route
```

Resultado obtido:

```text
default via 192.168.10.1 dev ens33 proto static
192.168.10.0/24 dev ens33 proto kernel scope link src 192.168.10.10
```

Esta configuração confirma que:

* o gateway predefinido é `192.168.10.1`;
* a interface utilizada para a comunicação é `ens33`;
* a rede local é `192.168.10.0/24`;
* o endereço de origem do DC01 na rede interna é `192.168.10.10`.

O endereço `192.168.10.1` corresponde à interface LAN do pfSense.

### Comando utilizado

```bash
ip route
```



---

## 4.5 Serviço Samba Active Directory Domain Controller

O estado do serviço Samba Active Directory Domain Controller foi verificado através do comando:

```bash
sudo systemctl status samba-ad-dc
```

O serviço encontra-se no estado:

```text
Active: active (running)
```

Este resultado confirma que o serviço principal do Samba Active Directory está activo no DC01.

O Samba AD DC é responsável pelas funções de controlador de domínio utilizadas pela infraestrutura TeckAlfa.

### Comando utilizado

```bash
sudo systemctl status samba-ad-dc
```

## 4.6 Serviços e portas de rede

A verificação dos serviços de rede activos no DC01 foi realizada através do comando:

```bash
sudo ss -tulpn
```

O resultado permitiu identificar diversos serviços associados ao funcionamento do Samba Active Directory.

### Principais portas identificadas

|  Porta | Protocolo | Serviço/Função                |
| -----: | --------- | ----------------------------- |
|   `53` | TCP/UDP   | DNS                           |
|   `88` | TCP/UDP   | Kerberos                      |
|  `135` | TCP       | RPC                           |
|  `137` | UDP       | NetBIOS Name Service          |
|  `138` | UDP       | NetBIOS Datagram Service      |
|  `139` | TCP       | NetBIOS Session Service / SMB |
|  `389` | TCP/UDP   | LDAP / CLDAP                  |
|  `445` | TCP       | SMB                           |
|  `464` | TCP/UDP   | Kerberos Password Change      |
|  `636` | TCP       | LDAPS                         |
| `3268` | TCP       | Global Catalog                |
| `3269` | TCP       | Global Catalog over SSL       |
| `9090` | TCP       | Cockpit                       |

### DNS

A porta `53` encontra-se activa em TCP e UDP, associada ao serviço DNS do Samba.

O DNS é fundamental para o funcionamento do Active Directory, uma vez que permite a resolução dos nomes e a localização dos serviços do domínio.

### Kerberos

As portas `88` e `464` encontram-se activas em TCP e UDP.

A porta `88` é utilizada pelo Kerberos para autenticação e a porta `464` está associada à alteração de palavras-passe Kerberos.

### LDAP

A porta `389` encontra-se activa e é utilizada pelo serviço LDAP/CLDAP.

Também está disponível a porta `636`, associada ao LDAP sobre SSL/TLS.

### SMB

As portas `445` e `139` encontram-se activas.

A porta `445` é utilizada pelo SMB directamente sobre TCP e é essencial para o acesso às partilhas de rede disponibilizadas pelo servidor.

### Global Catalog

As portas `3268` e `3269` encontram-se activas e correspondem aos serviços do Global Catalog do Active Directory.

### RPC

A porta `135` encontra-se activa, juntamente com portas dinâmicas utilizadas pelos serviços RPC.

### Cockpit

A porta `9090` encontra-se activa e corresponde ao serviço Cockpit, utilizado para administração através de uma interface Web.

A utilização do Cockpit será documentada posteriormente no capítulo **10 — Cockpit**.

### Comando utilizado

```bash
sudo ss -tulpn
```

## 4.9 Conclusão

A análise do DC01 confirmou que o servidor se encontra correctamente configurado na rede interna da infraestrutura TeckAlfa.

O servidor está identificado como `dc01.ad.teckalfa.pt`, utiliza o endereço IPv4 `192.168.10.10/24` e possui como gateway `192.168.10.1`, correspondente à interface LAN do pfSense.

O serviço `samba-ad-dc` encontra-se activo e em execução. A análise das portas de rede confirmou a presença dos principais serviços necessários ao funcionamento do Active Directory, incluindo DNS, Kerberos, LDAP, SMB, RPC e Global Catalog.

O DC01 constitui, assim, o componente central dos serviços de domínio da infraestrutura e será utilizado nas etapas seguintes para a validação do Samba Active Directory, DNS, Kerberos, utilizadores, grupos e partilhas de rede.
