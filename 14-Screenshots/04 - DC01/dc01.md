# 04 — DC01

## 4.1 Objetivo

O DC01 é o servidor principal da infraestrutura da TeckAlfa.

Este servidor desempenha funções essenciais na rede, nomeadamente:

- controlador de domínio;
- servidor Samba Active Directory;
- servidor DNS;
- autenticação através de Kerberos;
- gestão de utilizadores e grupos;
- disponibilização de recursos partilhados.

O servidor pertence ao domínio:

`ad.teckalfa.pt`

O nome completo do servidor é:

`dc01.ad.teckalfa.pt`

## 4.2 Identificação do servidor

O hostname do servidor foi configurado como:

`dc01`

O FQDN (Fully Qualified Domain Name) é:

`dc01.ad.teckalfa.pt`

### Comandos utilizados

```bash
hostname
hostname -f

## 4.3 Configuração de rede

O DC01 encontra-se configurado na rede interna da infraestrutura TeckAlfa, utilizando a interface `ens33`.

O endereço IPv4 atribuído ao servidor é:

`192.168.10.10/24`

A interface `ens33` encontra-se activa e operacional.

### Configuração identificada

| Parâmetro | Valor |
|---|---|
| Interface | `ens33` |
| Endereço IPv4 | `192.168.10.10/24` |
| Broadcast | `192.168.10.255` |
| Rede | `192.168.10.0/24` |
| Estado | `UP` |
